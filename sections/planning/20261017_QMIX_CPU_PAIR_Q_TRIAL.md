# CPU联合Q效用：下一轮限定试验协议

## 当前阶段与依据

本文件保留训练前的科学判定规则，并记录实现状态。候选名`cpu_pair_q_v9`的代码与工程验证已完成：230项测试及22项子测试通过，CUDA工程训练224步/55次更新、4回合冻结评估通过。正式8k开发训练尚未开始，没有新结构有效性结论。

v8同预算8k只完成69/605个、0.7719256610 J/完成。冻结替换CPU后完成292个、0.2904257054 J/完成；只替换route完成70个；联合替换365个。这些是使用既有Heuristic动作的混合策略诊断，不能用作QMIX训练成绩或证明新网络能达到相同水平。32个真实回放反传探针没有发现所测CPU分支梯度断开，10回合原轨迹复现的执行cycles、完成与能量核验通过。

旧v8同状态下频率Q独立于队列，只与队列Q相加，不能在合法频率相同的两个队列间表达相反频率偏好。该表示限制与冻结CPU诊断共同支持一项结构试验；尚不能认定是唯一根因。

## 唯一科学修改及边界

CPU分组使用联合可学习Q值覆盖Idle及原有合法队列／频率对。保留原七分支proposal和executor接口，保留原mask中的Idle和选队列但零频率；不加入强制服务、最高频率规则或Heuristic推理替代。保持原有Route、TX、GAT/GRU主体、QMIX单调mixer、环境、reward、优化器、Double-Q、TD(lambda=0.6)、当前权重前史重算、agent级epsilon触发与数值退火计划、target间隔200。

具体实现为队列Q与该队列条件频率Q相加：非Idle队列使用其专属频率行，Idle只使用队列Q。四个非Idle队列各保留四个原频率，频率输出从4个变为16个；七分支接口仍输出一个队列及一个频率。该参数化可以表达任意CPU对效用，无需新增状态信息。总参数为1,143,660，相比v8的1,142,112增加1,548个（0.13554%）；除整个频率分支外，其余参数的初始值哈希与v8完全一致。

新checkpoint schema为`factorized_gat_qmix.checkpoint.v8`，独立验证`cpu_utility`合同；实验名中的v9与checkpoint schema编号含义不同。新8k配置为`fa-gat-qmix-seed42-8k-cpu-pair-development.json`，hash为`ce44bb693b2b3db39069ebbdb1ce098b8dc82b97a1da0a35291426eb46da3d77`。真实旧v8 checkpoint已被两个加载入口拒绝；8k独立零步初始化的optimizer/replay为空、online=target，8k至16k仅预算扩展校验通过。

CPU组的执行贪心、online选择target动作和teacher replay取值必须使用同一联合效用和同一原合法动作集合。新结构必须有独立checkpoint合同／schema并拒绝旧结构续训；从零初始化，不加载失败v8的网络、optimizer或回放。增加参数量如实记录，不把它说成完全相同架构的比较。CPU组仍属现有强基线的动作适配工作，不变更主方法C或研究问题。

## 验证顺序

1. 构造同一状态两个队列的相反频率偏好，检验新表示确实能表达；检验全合法动作穷举与解码器最高效用一致，包括Idle、零频率、无任务和能量限制。
2. 检验teacher动作取值、分组效用及mask、Double-Q目标、联合CPU梯度与target冻结；原Route/TX选择不引入新的依赖或信息。
3. 检验批次／时间／agent轴、循环hidden、当前前史、探索随机流恢复、完整checkpoint恢复、旧schema拒绝和仅预算扩展；运行相关QMIX、Gate0及强基线回归。
4. 真正运行CUDA短程工程训练与冻结评估，验证真实参数更新、CPU组参数有限且变化、评估更新0、外部过程与守恒、指标文件一致。工程结果不得作开发成绩。
5. 通过后归档紧凑v8真实结果、诊断及文件清单；按既有授权清理不再需要的失败v8运行及旧配置，不触及C/A/B、共享源码、当前测试与新配置、`.agents/`或`knowledge/`。

## 开发预算和判定

seed42独立8k，每4k保存并冻结评估，仍使用既定五个开发场景、605个任务。主要科学对照为v8同预算69个、0.7719256610 J/完成，因为两者的探索和target设置一致；旧v6的166个、0.4324177329 J/完成作为已有竞争参照，不能将相对v6比较说成只有CPU一项变化。

原v8不续训。候选8k若不超过v8完成数或单位完成能耗更差，先诊断权衡，不自动扩展预算。推荐16k稳定性检查仍要求超过旧v6的166个，且J/完成不高于0.4324177329；满足该开发门槛也不代表强基线验收、跨seed稳定或统计显著。最终仍须对齐C及Local/Heuristic，并开展多seed正式比较。

训练与评估命令只在对话提供。执行权按用户最新有效指令处理；本协议本身不启动任何训练。
