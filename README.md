## 原8k发布版本摘要（历史记录）


本项目研究动态异构多UAV系统的任务分配与协同卸载，以相同物理和资源约束下完成更多任务为目标。当前活动实验为 seed42、8k、remote_stress_v2 的 A/B/C；入口为轻量的 main.py，实现位于 src/。

| 方法 | 定义 | DONE均值 | 完成率 |
|---|---|---:|---:|
| A | 原P1a分层Route baseline | 79.4 | 65.44% |
| B | Local与各Remote统一叶比较，保留Defer | 63.4 | 52.42% |
| C | B加35维物理关系特征 | 65.8 | 53.82% |

结果来自现有final模型在1042—1046五个开发评估seed上的评估。只有一个training seed；B/C尚未超过A。系统目标不设Local占比门槛，工程可运行不等于效果改善成立。
